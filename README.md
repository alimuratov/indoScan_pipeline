## IndoScan pipeline

All pipeline code lives under `scripts/src/`.

### Quickstart (recommended)

1) Configure your paths/params in `pipeline.config`
2) Run:

```bash
./run_pipeline.sh
```

This produces a Data2 export tree and the consolidated JSON:

- `output/data2/Roads/…`
- `output/data2/trial_output.json`
